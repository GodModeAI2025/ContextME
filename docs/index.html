Relevanz statt Archiv

ContextMe ist kein Wissensspeicher, sondern ein Modell deiner Relevanz. „Mobile" existiert als Thema einmal — seine Bedeutung ist eine Beziehung zum Kontext, keine Eigenschaft des Themas.

Reine Python-Standardbibliothek. Kein Konto, kein Dienst, kein API-Schlüssel, kein Netzwerkzugriff in der Laufzeit.

Vier Prinzipien

  1. Alles ist belegt. Jede Angabe trägt Quelle, Zeitpunkt und Herkunft: explicit (direkte Selbstaussage), document (importiertes Material), inferred (Interpretation). Eine Aussage im Dokument wird nie zur Selbstaussage hochgestuft.
  2. Relevanz ist zeit- und kontextabhängig. Häufigkeit klingt zeitlich ab, Massenimporte werden gedämpft, Duplikate zählen nicht doppelt. Ein Agentenabruf ist keine Aktivität von dir.
  3. Explizit schlägt abgeleitet. Eine Korrektur setzt sich gegen jedes statistische Muster durch. Ableitungen unter dem Grenzwert 0.70 landen in einer Prüfliste statt im Profil.
  4. Der Speicher gehört dir. Klartext-JSON in einem Ordner deiner Wahl. Du kannst ihn lesen, sichern, versionieren, löschen — und zwischen Claude Code und Codex mitnehmen.

In drei Schritten

Voraussetzung: Python 3.10+ und ein eingerichtetes Claude Code oder Codex mit Datei- und Ausführungszugriff.

1

Installieren

git clone https://github.com/GodModeAI2025/ContextME.git
cd ContextME
python3 skill/scripts/install.py --target both --workspace "$HOME/ContextMe"

Kopiert den Skill nach ~/.claude/skills/contextme und ~/.agents/skills/contextme und legt den privaten Arbeitsordner an. Unter Windows py -3 verwenden.

2

Profil erheben

/contextme  Nutze meinen eingerichteten Arbeitsordner. Erhebe mein
            Kontextprofil zuerst aus dem Material, das ich dir gebe,
            und frage nur wesentliche Lücken nach.

Du gibst Notizen, Transkripte oder freigegebene Mails — der Agent extrahiert Rollen, Projekte, Ziele und Arbeitsweisen selbst. Du schreibst kein JSON. In Codex entsprechend $contextme.

3

Kontext abrufen

python3 skill/scripts/contextme.py --workspace "$HOME/ContextMe" context \
  --context work --query "Aktuelle Rolle und Prioritäten" --max-chars 12000

Liefert ein begrenztes JSON-Paket mit Angaben, Quellen-IDs, Herkunft, Unsicherheit und Relevanz — statt „kopiere mein ganzes Leben in den Prompt".

Grenzen — ehrlich statt beruhigend

ContextMe verspricht keine Sicherheit, die es nicht herstellen kann. Was es nicht leistet, steht genauso in der Dokumentation wie das, was es leistet.

  • Die lokalen Skripte arbeiten ohne Netzwerk. Das heißt nicht, dass die semantische Verarbeitung lokal bleibt — was beim Modellanbieter landet, entscheidet der Host.
  • ContextMe hat keine eigene Verschlüsselung. Die Daten liegen als Klartext vor. Dateiberechtigungen und verschlüsselter Datenträger bleiben erforderlich.
  • Die Kontextfilter sind keine Zugriffssteuerung gegenüber einem Agenten, der ohnehin alle Dateien lesen darf. Für echte Isolation: getrennte Arbeitsordner.
  • Kein Hintergrunddienst, kein Postfach-Crawler. Der Skill liest nur, was der Host bereitstellt, und läuft nur, wenn er aufgerufen wird.
  • Sensible persönliche Attribute werden nicht aus Material erschlossen — nur bei ausdrücklichem Auftrag und bewusstem --allow-sensitive. Passwörter und Token nie.
  • Keine psychologische Diagnose, kein allgemeines Wissensarchiv. Ein Modell kann beim Interpretieren irren — deshalb bleiben Quelle, Herkunft und Korrektur Teil jeder Aussage.
